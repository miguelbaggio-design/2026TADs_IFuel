## 📖 Sobre o Projeto

Este projeto foi desenvolvido durante as aulas da disciplina de **Técnicas de Programação** do curso de **TADS (Tecnologia em Análise e Desenvolvimento de Sistemas)** no **IFSUL - Campus Venâncio Aires**.

O objetivo principal da atividade é capacitar os estudantes no fluxo de trabalho colaborativo moderno, ensinando na prática o uso das ferramentas **Git** e **GitHub**, além de aplicar conceitos de desenvolvimento backend com **PHP** e persistência de dados em banco de dados **NoSQL**.

---

## 🎯 Proposta do Sistema (Controle de Combustível)

A aplicação consiste em uma plataforma para **gestão e cálculo de média de consumo de combustível** de veículos automotores.

### ✨ Principais Funcionalidades

- [x] **Gestão de Usuários**: Cadastro e gerenciamento de usuários no sistema.
- [x] **Cadastro de Veículos**: Associação de carros aos seus respectivos proprietários.
- [ ] **Registro de Abastecimentos**:
  - Valor pago por litro de combustível.
  - Quantidade total em litros abastecidos.
  - Registro da quilometragem (odômetro) no momento da recarga.
- [ ] **Métricas e Desempenho**:
  - Média de consumo por quilômetro ($km/l$).
  - Acompanhamento dos custos e autonomia do veículo.
- [ ] **Persistência NoSQL**: Armazenamento flexível de documentos para usuários, veículos e históricos de abastecimento.
